# Game direction autopsy — 2026-10-19

## Scope and privacy

This public report records technical findings and remediation only. Provider account identifiers, credential fragments, customer billing amounts, workspace identifiers and raw diagnostic transcripts are intentionally omitted. The private reports remain the evidence source; this document is not a copy of them.

The supplied reports establish an interrupted initial build and a later model-invented cancellation during an attempted development-server restart. They do not include the saved game's source. Shared engine fixes cannot establish the precise custom-code root cause or retroactively repair an existing saved game.

The original finding tally is **4 self-healed, 3 workarounds, 4 skipped/unestablished, 6 broken/imperfect, 5 struggle points = 22 findings**. Four additional defects were reproduced during investigation. Total: **26 findings, 9 implemented fixes, 17 blocked findings**. Queue closure takes effect only when this change merges.

## Shared fixes and proof

- Q-1200: camera-relative movement used the destination orbit yaw while the actual view was still damping from the opposite side. `CameraRig.yaw` now derives heading from the displayed camera. Regression exercises W/S/A/D on every frame of multiple orbit turns, rather than waiting 600 frames to assert the endpoint.
- Q-1201: chase damping could start in front of a newly followed or respawned vehicle. The chase camera now repositions behind the vehicle when its previous location is in the front hemisphere; ordinary following still damps. Car, motorcycle and bicycle are tested from frame zero through half-turns and respawns.
- Q-1202: the prompt taught world -Z but recipe examples initialized cars/bikes facing +Z. Their chase views were internally correct, but copying their motion into a fixed +Z camera mixed conventions. Examples now rotate the model before `createVehicleState`. Local model +Z is preserved for all existing models and controls.
- Q-1203: the Start Game button scaled forever; normal browser clicks waited forever for a stable bounding box. Its pulse now changes opacity only. Reduced-motion browser support remains an additional safeguard, not the only way to click a game.
- Q-1204: `stop_build` trusted the model's invented reason as a user quote. The composition root now supplies trusted latest user text, retained after steering queue consumption. Empty, stale and fabricated quotes are refused before abort or billing side effects. Intent classification remains the model's job; no stop-word phrase list is introduced. Platform-composed fix requests cannot authorize this tool.
- Q-1205: vehicle/road option and result types were absent from the recipe's early contract. The contract is now extracted from the generated declarations and placed before the 3D example. It documents `Motorcycle.root`, supported options and vehicle state, and survives the actual handoff clip.

Reversion probes: restoring destination yaw, removing the behind-camera guard, bypassing trusted stop text and restoring geometric button pulse each failed their regression suite. These tests execute generated game code with real Three.js geometry/math; WebGL/audio alone are stubbed. They are not evidence of playtesting the inaccessible saved game on a physical phone.
