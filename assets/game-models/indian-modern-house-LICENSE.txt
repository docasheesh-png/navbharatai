Asset scope and accuracy
This GLB contains a two-level architectural shell, interior room partitions, furnished room geometry, a front entrance opening, staircase geometry, upper-floor stairwell opening, balcony and roof terrace. It is a visual architectural asset, not a complete game-ready physics scene. It contains no engine-native collision proxies, baked NavMesh, interactive door animation, character controller, embedded texture images, or animation clips. The target Game Maker must supply and validate collision, navigation, door interaction, lighting, and runtime performance.

The packaged GLB is stored gzip-compressed in the repository. The catalogue pins the SHA-256 of the decoded GLB bytes; the server decompresses it under the asset-size cap and verifies the hash before serving it.
